# Koko

Koko is a greenfield Java 25 JavaFX desktop application for learning Japanese vocabulary. It maintains a global vocabulary library whose cards can be organized into one or more study decks.

Read the [User Guide](docs/UserGuide.md) for setup, vocabulary management, review, and instructions on how to use the app.

Try the [example deck](examples/koko-sample-deck.json) using **Transfer > Import deck...**.
